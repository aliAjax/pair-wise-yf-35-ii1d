常用接口

POST /api/whereabouts                    运动员申报：athlete_id, period(2026-Q3), location, window_starts_at
POST /api/entities/<id>/actions         {action: "amend"|"close", ...}   改址留版本 / 季度关档
GET  /api/whereabouts/effective?athlete_id=&period=&check_at=   按检查日期读取有效版本
GET  /api/whereabouts/<id>/versions      全部历史版本
POST /api/dispatches                     检查员派单：athlete_id, period, check_at（地点缺失/时段已过返回 400）
POST /api/entities/<id>/actions         {action: "execute", data:{outcome:"hit"|"miss"}} / {action:"cancel"}
GET  /api/miss-count?athlete_id=         滚动 12 个月未命中次数
GET  /api/dashboard                      本页总览数据
